# Asset provenance and licensing

## Supplied original collections

The initial library was assembled from these user-provided inputs:

- `Glow-Cursor-Forge-Auto-Theme-Installer(1).zip`
- `GlowCursors (main).rar`
- `NeonPulse_Cursors_With_AutoInstaller.rar`

The 16-theme ZIP was copied byte-for-byte into the original local bundle. The two RAR files were retained byte-for-byte under `source-archives/`. The RAR collections were extracted and repacked as convenient ZIP downloads. The extracted assets retain their pack-specific folder structures and installers.

## QUIETFORM collection

The fourth collection was supplied as `QUIETFORM_Download.zip` for inclusion in the library. The inspected archive contains 20 families, 360 animated ANI files, 360 static CUR alternatives, previews, manifests, design notes, technical reports and Windows installation scripts.

The archive's SHA-256 at inspection was:

`4d2f06adab5fadf6d5f27ae9233028919a7992058e8e4381be741ce4cf357689`

Its included quality report describes structural validation of the ANI/CUR files. It also states that the package has not been installed and smoke-tested on a physical Windows 10/11 machine in the build environment.

## Reference pages

The two Arena generator URLs are listed as related references, not as asset sources or official Windows documentation. The repository does not claim to own either website or its source code.
