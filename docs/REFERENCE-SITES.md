# Reference generator websites

The two user-provided Arena pages were inspected using a live browser on **12 November 2026**. Arena identifies the pages as user-generated content. These are reference links, not official Windows documentation.

## Reference 1 · six-theme Glow Cursor Forge generator

**URL:** https://01a1cc5a-9188-7399-bb27-6279ce3926ee.arena.site/

Observed features:
- Six themes: Cyber Cyan, Neon Magenta, Toxic Lime, Solar Flare, Plasma Violet, and Aurora Spectrum.
- Fifteen cursor roles per theme, for up to 90 ANI files.
- Frame options: 16, 24, or 32.
- Cursor sizes: 32, 48, or 64 pixels.
- Pulse speed: Fast, Normal, or Chill.
- Default loop duration described as approximately 1.20 seconds.
- Per-theme INF installers, a master BAT installer, a README, and individual cursor downloads.
- The page says generation occurs locally in the browser.

**Matching supplied pack:** `GlowCursors-5-Themes.zip`. The supplied archive has five themes and 75 ANI files, so it is a subset rather than the complete 90-file output. The supplied subset includes Aurora Spectrum, Cyber Cyan, Plasma Violet, Solar Flare, and Toxic Lime.

## Reference 2 · sixteen-theme Glow Cursor Forge generator

**URL:** https://01a1cc83-38e3-7b7d-baeb-71ddbce0c760.arena.site/

Observed features:
- Sixteen themes: Cyber Cyan, Neon Magenta, Toxic Lime, Solar Flare, Plasma Violet, Aurora Spectrum, Crimson Pulse, Ocean Abyss, Arctic Frost, Emerald Matrix, Sunset Drift, Golden Hour, Ghost White, Inferno, Prism Pulse, and Bubblegum Pink.
- Fifteen Windows pointer roles per theme, for up to 240 ANI files.
- Animation styles: Pulse, Breathe, Shimmer, and Rainbow.
- Body fills: Neon, Glass, and Solid.
- Pulse speed: Fast, Normal, Chill.
- Frame options: 16, 24, 32, or 48.
- Size options: 32, 48, 64, or 96 pixels.
- Per-theme INF installer, batch installer, preview sheet, default-restore helper, and README.
- The page advertises Windows 7 / 10 / 11 compatibility and says processing is local in the browser.

**Matching supplied pack:** `Glow-Cursor-Forge-16-Themes.zip`. The supplied archive contains 16 theme folders and 240 ANI files. Its README records one export preset: 32×32, 48 frames, Breathe animation, Glass fill, and 110% glow.
