# Download packages

This folder is the intended home for the four ready-to-use ZIP archives. The repository maintainer will upload the ZIP files manually after the documentation update. Until then, the archive links are planned paths and will not download from GitHub.

## 1. Glow Cursor Forge · 16 Themes

- **Archive filename:** `Glow-Cursor-Forge-16-Themes.zip`
- **Themes:** 16
- **Animated cursors:** 240 ANI (16 × 15 roles)
- **Reported size:** 22,131,398 bytes
- **Style:** Neon palettes, glow effects and colourful motion.
- **Related generator:** [Open 16-theme generator](https://01a1cc83-38e3-7b7d-baeb-71ddbce0c760.arena.site/)
- **Upload destination:** `downloads/Glow-Cursor-Forge-16-Themes.zip`

Themes: Cyber Cyan, Neon Magenta, Toxic Lime, Solar Flare, Plasma Violet, Aurora Spectrum, Crimson Pulse, Ocean Abyss, Arctic Frost, Emerald Matrix, Sunset Drift, Golden Hour, Ghost White, Inferno, Prism Pulse and Bubblegum Pink.

The supplied export notes record 32×32 frames, 48 steps, Breathe animation, Glass fill and 110% glow.

- **Reported size:** 3,751,130 bytes

## 4. QUIETFORM · 20 Professional Themes

- **Archive filename:** `QUIETFORM_Download.zip`
- **Themes:** 20
- **Animated cursors:** 360 ANI (20 × 18 cursor types)
- **Static cursors:** 360 CUR
- **Reported archive size:** 13,138,925 bytes
- **Archive entries:** 891
- **Style:** Minimalist, professional, neutral and subtly animated.
- **Related generator:** No separate generator link is required for this packaged collection.
- **Upload destination:** `downloads/QUIETFORM_Download.zip`

Themes: Graphite Standard, Soft Slate, Paper & Ink, Quiet Navy, Dusty Blue, Sage Studio, Charcoal Outline, Warm Grey, Frosted Neutral, Blueprint Precision, Editorial Monochrome, Rounded Utility, Fine-Line Technical, Soft Ceramic, Carbon Precision, Pebble Minimal, Muted Teal, Ink & Chalk, Nordic Neutral and Contemporary Office.

Every family includes 18 cursor types: Normal Select, Help Select, Working in Background, Busy, Precision Select, Text Select, Handwriting, Unavailable, Vertical Resize, Horizontal Resize, Diagonal Resize 1, Diagonal Resize 2, Move, Alternate Select, Link Select, Location Select, Person Select and Pan / Grab.

The archive includes 32×32, 48×48 and 64×64 representations within ANI frames, 2,448 frames in total, PNG/SVG family previews, a complete CSV manifest, technical notes, a numbered installer and a restore utility. Run `INSTALL_QUIETFORM.bat`, enter a family number from `01` through `20`, and the installer assigns the selected scheme for the current Windows user. `RESTORE_QUIETFORM.bat` restores the pre-install settings backup.

The package reports structural validation for all 360 ANI and 360 CUR files. It has not yet been smoke-tested on a physical Windows 10/11 system. See [QUIETFORM notes](../docs/QUIETFORM.md).
