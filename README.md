# Animated Cursor Library

A curated library of animated Windows cursor collections, with four downloadable packs covering expressive neon themes and restrained professional designs.

> **Library totals:** 4 collections · 46 theme folders · 775 animated `.ani` files · 360 static `.cur` alternatives (included in QUIETFORM). The four ZIP archives are documented below. Their binary files are not yet in this repository; the repository maintainer will upload the four ZIP files manually. See [BINARY-ASSET-UPLOAD.md](BINARY-ASSET-UPLOAD.md).

## At a glance

| Collection | Themes | Animated ANI files | Static CUR files | Design direction |
|---|---:|---:|---:|---|
| Glow Cursor Forge | 16 | 240 | Not inventoried | Neon, glow and colourful animated themes |
| GlowCursors | 5 | 75 | Not inventoried | Compact subset of the GlowCursors generator themes |
| Neon Pulse | 5 | 100 | Not inventoried | Neon palette with extra application-oriented cursor roles |
| QUIETFORM | 20 | 360 | 360 | Minimal, neutral, professional and subtly animated |
| **Total** | **46** | **775** | **360** | Four separate collections |

The counts above refer to the supplied archives and their documented inventories. The 360 static `.cur` files are confirmed in QUIETFORM. The other three archives are catalogued by their supplied ANI counts; their `.cur` contents, if any, have not been separately inventoried.

## 4. QUIETFORM · 20 Professional Themes

**Archive:** `QUIETFORM_Download.zip`  
**Download path after upload:** [downloads/QUIETFORM_Download.zip](downloads/QUIETFORM_Download.zip)  
**Archive size:** 13,138,925 bytes (about 13.14 MB)  
**Inventory:** 20 families × 18 cursor types = **360 ANI files**, plus **360 static CUR files**

QUIETFORM is the professional, minimal and neutral collection. Its visual direction is deliberately different from the neon packs: graphite, charcoal, ivory, slate, grey, muted navy, dusty blue, sage, muted teal and stone tones. It avoids rainbow palettes, neon glow, gold effects and unnecessary decoration.

Animations are intended to be quiet and functional: subtle breathing, restrained progress indicators, gentle movement and small shape transitions. Each family follows a coordinated design system.

### Technical contents

- 360 animated `.ani` files.
- 360 static `.cur` alternatives for reduced-motion use.
- 32×32, 48×48 and 64×64 cursor images embedded in each ANI frame.
- 2,448 animation frames across the collection.
- 20 PNG and 20 SVG family preview sheets, plus the preview gallery assets in the archive.
- A complete CSV manifest with frame counts, timing, hotspots, sizes, file lengths and SHA-256 values.
- Design-system notes, cursor catalog, technical notes and quality-assurance report.
- A numbered Windows installer and a restore utility.

### Automatic Windows installer

After extracting the archive, run `INSTALL_QUIETFORM.bat`. Enter a family number from `01` to `20`; the installer copies the selected family's cursor files, registers the scheme and activates it for the current Windows user. It saves the pre-install cursor settings before the first QUIETFORM installation. Run `RESTORE_QUIETFORM.bat` to restore that backup.

Pan / Grab is included as an extra cursor for applications that support custom cursors; Windows does not expose a standard system-wide scheme slot for it. The installer assigns the 17 named Windows pointer roles described by the package documentation.

The archive's own structural report records all 360 ANI and all 360 CUR files as passing its parser checks. This is structural validation, not a substitute for a live Windows 10/11 installation and playback test. The installer has not been smoke-tested on a physical Windows machine in the build environment.

See [the full QUIETFORM notes](docs/QUIETFORM.md) and [Windows installation guide](docs/WINDOWS-INSTALLATION.md).

## Installing a collection on Windows

1. Download the ZIP archive after it is uploaded to the repository.
2. Extract the ZIP to a normal folder. Do not run installers from inside the ZIP preview.
3. Use the collection's included installer when available, or follow [Windows installation](docs/WINDOWS-INSTALLATION.md).
4. To assign cursors manually, open Mouse Properties with `Win + R` → `main.cpl` → **Pointers**, choose a role, select **Browse**, and choose the matching `.ani` or `.cur` file.
5. Review each package's own README before installing. Different collections may contain different installer workflows.

For QUIETFORM specifically, run `INSTALL_QUIETFORM.bat` and enter the desired two-digit family number.

## Validation and limitations

The original three packs are catalogued using the supplied archive inventories and extraction notes. QUIETFORM includes a package-level quality report and manifest. Its reported parser checks include RIFF/ACON structure, ANI headers, embedded CUR frames, image sizes, hotspots, transparency, timing and duplicate-artwork checks.

No claim is made that every cursor has been runtime-tested on every Windows version or in every application. Some applications override the system cursor scheme, and application-oriented cursor roles may not be available system-wide.
